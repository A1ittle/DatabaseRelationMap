# 项目总体设计

> v1.0 更新：本文保留产品/领域/架构与验收背景。已收敛的技术栈、环降级字段、数据导入页面、查询协议和默认决策统一以 [完整实现设计](07-implementation-design.md) 为准；接口字段以 `spec/v1/openapi.json` 为准。早期“待确认”条目不阻止按明确默认值完成本地编码，真实数据/SSO/目标环境仍需独立验收。


## 1. 项目定位

程序血缘地图是面向开发、测试、运维和架构人员的对象级下游依赖探索工具。用户选定一张表后，能够回答：哪些对象直接依赖它；依赖沿哪些加工或调用环节传播；不同分支在哪里汇合；哪些 Java 程序是本次分析的终点。

“影响”定义为**基于当前采集关系可达的潜在影响**。本系统不据此断言程序一定受损，也不以“查不到关系”自动判定安全。页面始终携带来源版本、采集时间和覆盖状态。

## 2. 已确认边界与暂定范围

已确认：根必须是表；对象级 table/view/procedure/java；仅下游；下游节点间关联应能发现；Java 不继续展开。

| 阶段 | 能力 |
|---|---|
| V1 必需 | 表检索、下游树、跨支列表和定位、总览、影响清单、最短路径、节点及关系详情、数据接入校验、权限过滤、版本一致性、错误/未采集/不完整状态 |
| V1 暂按建议加入 | 可复现链接、当前查询刷新、最近访问（仅会话）、清单分页、基本运行诊断 |
| 后续选项 | 影响清单导出、环簇展开、系统/负责人聚合、版本差异、收藏、采集调度管理 |
| 当前不纳入 | 字段级解析、上游和双向图、Java 出边展示、关系编辑审批、自动代码修改、风险自动裁决、全企业数据治理平台 |

自动采集不是“地图前端”的附带小功能。若尚无对象关系数据，需单独确定数据库种类、SQL 方言、Java 框架、存储过程语法与解析覆盖边界。

## 3. 用户与任务

| 用户 | 典型动作 | 产出 |
|---|---|---|
| 开发人员 | 查根表→筛选→看节点/跨支→找 Java 路径 | 一条可解释的依赖链和对应关系证据 |
| 测试人员 | 看影响清单→按类型/系统定位对象 | 候选回归范围；不等同最终测试计划 |
| 运维/架构人员 | 看整体规模→展开主分支→查汇合节点 | 调查线索与上下文链接 |
| 数据维护人员（建议角色） | 接入数据→看校验报告→发布快照 | 可查询、可追溯的数据版本 |

角色名称不绑定权限实现；实际对象授权由现有组织系统提供。

## 4. 信息架构

V1 以一个工作台为主，避免为了“完整项目”扩展出没有需求依据的大屏和管理门户。

```text
程序血缘工作台
├─ 表入口：搜索/选择、系统与环境定位
├─ 查询上下文：当前表、数据时间、版本、覆盖状态
├─ 工作视图：下游树 | 分层总览 | 影响清单 | 调用路径
├─ 展示控制：对象类型、主树层级、展开/收起
├─ 摘要与图例：潜在下游、Java 终点、跨支边、实际绘制对象数
└─ 详情：对象属性、主关系、跨支关系、证据、换根/定位
```

“数据接入与质量”可先通过运维接口/批处理实现，未确认前不强制建设管理页面。

## 5. 四种视图的产品契约

| 视图 | 默认呈现 | 主要动作 | 关键约束 |
|---|---|---|---|
| 下游树 | 根与主树第一层，列内折叠 | 选中、展开一层、收起、设为根、跨支定位 | 一节点一卡片；其余入边保留为跨支；超预算引导总览 |
| 分层总览 | 按展示层级×类型的数量簇 | 看数量、分页查看簇成员、定位 | “全部”表示查询范围全部，不表示全量渲染卡片 |
| 影响清单 | 全部授权可达下游，默认排除根 | 按类型/系统筛选、分页、看关系 | 独立于画布展开状态；同对象只计一次 |
| 调用路径 | 根到选定下游的一条最短关系路径 | 搜索目标、查看每步边类型和证据 | 包含跨支；不沿主父指针伪造最短路；不是运行时间线 |

原“调用路径”名称可以先保留，但说明改为“关系链路，包含读取、写入、派生或调用”。未来是否更名为“依赖路径”待产品确认。

## 6. 核心用户流程

1. 进入页面，选择系统/环境内的表；存在同名表时显示完整命名空间。
2. 服务端检查权限及采集状态，建立固定版本查询上下文。
3. 展示主树第一层与完整范围摘要；首次选中根。没有数据时明确显示原因。
4. 单击节点打开详情并高亮主路径；跨支关系即使另一端未上画布，仍可在详情发现。
5. 点“展开”只增加该节点一层主树子节点，分页有独立“更多”；点跨支对象则定位它和必要祖先，不把跨支改成主父边。
6. 评估范围进入清单；理解体量进入总览；解释关系进入路径。
7. 对下游表执行换根，创建新查询上下文、清空旧展开、选中和路径目标；保留合法视图及类型偏好，层级重置为 1。

## 7. 交互补充决策（建议）

- **筛选只影响呈现，不改变血缘拓扑。** 不因隐藏视图类型而把“表→视图→Java”改成直接“表→Java”。图中若中间对象隐藏，提示“路径含被筛选类型”，提供“显示完整路径”；路径视图临时显示路径必需的全部类型。
- 根是查询锚点：至少一类开启时始终保留根；全部关闭则保持原型空态。此项修订了原型关闭 table 即隐藏根的行为。
- `+N` 是尚未显示的主树子对象数；“跨支 N 条”独立展示，不再因 `+N` 徽章存在而完全遮蔽跨支提示。
- 实线/虚线只表达主树/跨支；读取/写入等通过文本标签和详情说明。可信状态使用单独图标和文本。
- 默认一层是**展示树的一层**，不是“所有直接读取者”。根详情提供直接关联数量及入口，使位于深层的直接跨支消费者不会被误认为不存在。
- 搜索结果标出“当前下游”或“切换为根”；非表且不在当前下游的对象不在本页可选范围内。
- 已采集且无下游显示“当前数据范围内暂无下游”；未采集显示“尚未采集”；查询截断显示“不完整”，三者不可共用同一种空态。
- 对权限不可见对象不显示名称、ID、数量或隐藏节点占位。一般提示只说“结果基于当前权限与已采集数据”，不透露隐藏对象是否存在。

## 8. 视觉与可用性基线

沿用原型浅底、细边框、等宽技术名、类型图标。绿色重点用于当前表和选中链路；根列不再套外框。桌面详情约 320px，窄屏用底部可收起面板。所有核心动作都有可聚焦按钮，双击换根保留等价按钮，键盘快捷键在输入框中不拦截正常输入。

长对象名用两行省略/换行，详情提供完整名称及复制；不能只依赖鼠标悬停。错误信息在对应区域呈现，单节点展开失败不清空整图。布局变化尽量保持选中节点位置；减少动态效果偏好下关闭非必要动画。最终需在目标浏览器和真实长名称数据上验收。
