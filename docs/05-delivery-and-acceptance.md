# 开发阶段与验收设计

> v1.0 更新：本文保留产品/领域/架构与验收背景。已收敛的技术栈、环降级字段、数据导入页面、查询协议和默认决策统一以 [完整实现设计](07-implementation-design.md) 为准；接口字段以 `spec/v1/openapi.json` 为准。早期“待确认”条目不阻止按明确默认值完成本地编码，真实数据/SSO/目标环境仍需独立验收。


## 1. 实施阶段

本轮只完成设计梳理；下表是后续开发计划，不代表已执行。工期取决于数据接入和团队，不在缺少约束时承诺日历日期。

| 阶段 | 工作包 | 退出条件 |
|---|---|---|
| M0 设计冻结 | 获取真实样本、明确来源/Java 粒度/方向、评审关键规则、确认栈与环境 | 样本字段映射、决策记录和验收基线一致 |
| M1 数据与查询纵切 | 一个真实来源→校验→快照→鉴权→下游/主跨分类/统计/路径 API | 真实小图逐边对照；边界用例通过；无假数据替代 |
| M2 核心工作台 | 表入口、默认一层树、详情、跨支发现、连续懒展开、换根、版本与错误态 | 用户能独立走完一次关系调查；至少一个真实汇合场景 |
| M3 四视图闭环 | 总览/清单/路径、分页、搜索定位、URL 恢复及筛选 | 四视图同版本同口径；列表数与完整计算一致 |
| M4 规模与运行验收 | 高扇出/环/权限变化/失败恢复/离线环境、性能与部署演练 | 真机可用，验收证据完备，已知限制获确认 |

如果没有现成血缘数据，M1 前增加“采集可行性与解析覆盖”阶段；不能一边假设自动解析已完成，一边估算纯前端工期。

## 2. 可拆分开发任务

| 任务 | 主要责任 | 依赖 | 可审查产物 |
|---|---|---|---|
| T01 真实数据映射 | 数据/后端 | M0 样本 | 对象身份和边方向映射、异常样本 |
| T02 快照接入 | 后端 | T01 | 幂等导入、质量报告、原子发布与回退 |
| T03 图领域模块 | 后端 | 决策冻结 | 无 UI 依赖的算法模块和明确反例测试 |
| T04 契约与授权 | 后端 | T03 | 完整 OpenAPI、示例响应、权限与上下文测试 |
| T05 图渲染选型 | 前端 | 固定样本/契约草案 | 一种引擎的代表性交互及性能记录 |
| T06 状态和核心页 | 前端 | T04/T05 | URL、并发控制、默认树、详情、跨支发现 |
| T07 三个辅助视图 | 前端/后端 | T04/T06 | 总览、影响清单、最短路径及一致性证据 |
| T08 验收与部署 | QA/运维/开发 | 上述任务 | 场景结果、性能报告、部署和恢复说明 |

先让开发理解原型，再按领域模型重建组件与服务；不把单文件 HTML 拆成若干文件就视为工程化完成。

## 3. 关键验收用例

| ID | 场景/输入 | 必须观察到的结果 |
|---|---|---|
| A01 | 根→视图→表→Java | 仅下游，根唯一；Java 停止展开；路径有原始关系证据 |
| A02 | 下游视图有外部维表侧输入 | 维表不进入当前根地图，不伪造其与根的关系 |
| A03 | 两分支汇合 | 一条主父边、其他入边为跨支；未绘制另一端时仍可从详情发现 |
| A04 | 主树长链+直接短跨支 | layoutRank 与 minHops 分开；最短路径使用跨支 |
| A05 | 同端点 reads/derives | 两条逻辑关系保留；仅一条主边；孩子和影响对象不重复 |
| A06 | 数据顺序随机重排/分页顺序交换 | 同一稳定键输入得相同主父、rank、去重计数 |
| A07 | 自环且有后继 | 自环记录为质量信息，后继仍正确分层，无假父边 |
| A08 | 真实有向环并有尾部后继 | 明确树降级；清单仍包含合法可达尾部；路径有界终止 |
| A09 | Java 原始出边指向其他表 | 事实层保留，当前查询不沿该边遍历；文案不否认事实 |
| A10 | 先展开 A 再 B，和先 B 再 A | 跨支闭包一致，不因先后次序漏线 |
| A11 | 主树超过三层 | 可逐层展开到任意预算允许的深度，不被旧 depth+2 条件卡住 |
| A12 | 高扇出 500 子对象 | 默认有界展示；N 精确；连续分页无重无漏；全部进入总览 |
| A13 | 只显示 Java，隐藏中间视图 | 不制造表→Java 直接边；提供完整路径恢复提示 |
| A14 | 未采集/已采集无下游/来源不完整 | 三种状态区分；不完整数字标下界或未知 |
| A15 | 隐藏中间节点权限 | 搜索/图/详情/计数/路径均不泄露；不得越过隐藏节点把尾部拼回 |
| A16 | A 根慢请求后返回，已切 B 根 | B 页面不被 A 覆盖；旧上下文缓存不混入 |
| A17 | 展开期间发布新快照 | 当前查询保持旧版本，刷新后整体换新；游标失效明确 |
| A18 | 快照删除、链接过期、选中已撤权 | 给出明确恢复动作，无越权、无悬空详情 |
| A19 | 特殊字符 ID/长 Java 名/中文/引号 | 名称按文本安全呈现，定位和复制准确，卡片不溢出 |
| A20 | 键盘与窄屏 | 搜索、页签、展开、详情和换根均可操作，输入框不被快捷键抢占 |
| A21 | 全局数据有 500 节点但部分不连通 | 仅统计当前授权可达对象，全库总数不冒充下游总数 |
| A22 | 导入失败及同批次重试 | 上一快照继续可用，重试无重复记录，质量报告可追溯 |

原 10/9/3 样例是其中一项兼容回归，不足以替代 A01–A22。样例中并列顺序规则若正式变更，必须同步设计记录与期望值。

## 4. 性能与可用性目标（待确认，不是本轮实测）

初始建议在固定设备、浏览器、网络延迟、数据规模和并发数下测试。并发量由用户提供后冻结，不能用单用户热缓存代表生产性能。

| 指标 | 初始目标 |
|---|---|
| API 查询上下文创建 p95 | ≤2 秒，分别报告冷/热缓存 |
| 默认首屏可交互 p95 | ≤3 秒，含数据请求、布局和渲染 |
| 子节点展开 p95 | ≤1 秒，含网络；按每页 50 节点测 |
| 已加载对象选中与详情框响应 p95 | ≤100ms，详情远程内容可独立加载 |
| 搜索响应 p95 | ≤500ms，包含服务请求，不含人为输入时间 |
| 默认画布/硬上限 | 100/200 实际对象预算，超过用折叠/总览 |

测试数据同时覆盖：真实最大根、500 子节点高扇出、长链、多分支汇合、多种平行关系。记录节点数、边数、实际渲染数、首次/缓存查询、分位时延和失败率。接口查询总预算、全库容量和刷新频率待确认后加入。

用户可用性验证：让代表性开发/测试人员分别完成“找直接依赖”“查跨支汇合”“列出受影响 Java”“解释一条路径”，观察是否误把未展开当无依赖、跨支当低可信或 Java 终点当真实无出边；有这些误解即视为需整改。

## 5. 本轮完成与尚未完成

本轮：源原型与交接件读取并保留；正常样例回归；独立边界探针；设计文档、决策清单和验收计划。尚未：业务代码、正式 schema 校验、真实数据验证、组件交互全量验收、性能压测、部署。

## 6. 待确认决策表

| 决策 | 当前建议/假设 | 谁/何时决定 |
|---|---|---|
| D01 数据来源 | 已有对象关系数据接入；若只有源码需另设采集阶段 | 用户，M0 |
| D02 技术与环境 | 沿用团队框架/数据库/鉴权；是否内网离线待定 | 用户/技术负责人，M0 |
| D03 Java 粒度 | 类、作业或服务选定一个主要统计单位 | 数据负责人，M0 |
| D04 调用方向 | 调用者→被调用者计潜在关联，明确不是数据必然传播 | 业务/数据负责人，M0 |
| D05 布局父边规则 | DAG 延续最长路线和强度；补稳定键 | 产品/后端，T03 前 |
| D06 环处理 | V1 树受控降级、保留清单与路径；环簇后置 | 产品/后端，T03 前 |
| D07 过滤交互 | 筛选不重算拓扑、根保留、路径可临时恢复类型 | 产品/前端，T06 前 |
| D08 来源覆盖和新鲜度 | 明确每来源范围、同步周期、保留期与不完整标识 | 数据/运维，T02 前 |
| D09 规模与并发 | 核对 500+/300+ 口径、全库规模及用户并发 | 用户/运维，M0 |
| D10 导出/审批/管理页 | 暂不作为 V1 交付前提 | 用户决定是否新增范围 |

这里的“待确认”是决策待定，不代表设计梳理遗漏。开发启动应先处理 D01–D09 对应阶段的前置项；不把建议自动写成已批准需求。
